# 09 · Decisiones

## Cerradas
| Tema | Decisión |
|---|---|
| Plataforma | iPhone (y Android por añadidura), Expo + TypeScript |
| Guardado | Local, offline |
| Idioma | Español |
| País | Genérico |
| Tono | Humor negro, caótico, algo más realista, adulto, sin límites (salvo regla fija: sin sexo con menores) |
| Base de sistemas | Los de BitLife |
| Stats | Los de BitLife (Felicidad, Salud, Inteligencia, Apariencia) |
| Muerte | Se puede seguir con hijo/heredero |
| Modos | Sandbox + escenarios/desafíos |
| IA | Base sin IA; capa opcional con clave gratuita propia más adelante |
| Sonido | Solo sonidos de interfaz mínimos |
| Iconos | Íconos vectoriales, no emojis |
| **Época de arranque** | **Aleatoria**: cada vida nace en un año al azar dentro de un rango (ver 06). Los eventos históricos y la tecnología dependen del año. |
| **Avatar** | **Personalizable** (cambiado tras probar el MVP): nombre, género, piel, ojos, peinado y color de pelo, dibujado con SVG. |
| **Sistemas prioritarios (Fase 2)** | Elegidos por mí: **1) Relaciones, 2) Carrera/Trabajo y dinero, 3) Crimen y justicia.** Son los que más generan historias y decisiones interesantes. Salud, propiedades y fama van después. |
| Instalación permanente en iPhone / PWA | Se decide más adelante |

## Abiertas (no bloquean el MVP)
- Nombre del juego (provisorio: VidaSim).
- Rango de años de nacimiento aleatorio (propuesta: 1950–2010) y si se puede fijar a mano.
- Escenarios/desafíos iniciales (se definen en Fase 3).
- Dificultad: propuesta = una sola dificultad "realista con caos" en el MVP.
- Preguntas de mundo persistente: ver [06-mundo-persistente.md](06-mundo-persistente.md).
- Cuenta de Google para API key gratuita (solo si se hace la capa de IA).
